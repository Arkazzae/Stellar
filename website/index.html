Talk on your own server.

Stellarr is self-hosted text and voice chat for small groups who already know each other. One Docker image runs all of it. Messages and files stay on your server, and calls need no third-party media service.

Translate inside the chat

Mozilla's Bergamot engine translates messages right in your browser, with no character limits. The models download from your own server and are checked against their SHA-256 hashes before use.

English and Polish work today, with more languages planned.

Private by design

Your server stays on your machine, with no cloud accounts, ads or subscriptions. Noise suppression and translation run in the browser, and your server fetches link previews, so friends' browsers never contact outside sites.

Optional 1:1 end-to-end encryption covers DMs, file uploads and calls, with a recovery code for your key backup and safety codes for verifying contacts. It is experimental and has not been independently audited yet.

Easy to host,
(over)engineered inside.

No Postgres, Redis, LiveKit and five separate containers to wire up just to hang out with friends. The web app, Rust chat API, custom Rust media server and SQLite database all run in one container.

  • One containeramd64 or arm64, about 120–150 MiB of RAM at idle
  • One folderEverything lives in /data/stellarr, so a backup is one copied directory
  • CockpitAccounts, live logs, backups and settings in the browser

Start your server

With Git and Docker Compose 2.24 or newer, start by checking out the server release.

$ git clone --depth 1 --branch server-v0.2.1 https://github.com/Arkazzae/Stellarr.git
  1. Choose your addressIn the new Stellarr directory, copy .env.example to .env and set STELLARR_VERSION=0.2.1. For other devices, set your domain and media IP there too.
  2. Start the serverReview docker-compose.yml, then run docker compose up -d --wait. Find the setup code with docker compose logs stellarr | grep 'Setup code'.
  3. Create your accountOpen /setup on your HTTPS address, or https://localhost/setup for a local trial. For internet calls, forward HTTPS and the media port (default 49000, UDP and TCP) and configure trusted TLS.
